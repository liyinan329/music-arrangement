# 序曲《时间》现场编配稿

以原作的“时间”主题与合唱为中心，用时钟脉动、弦乐长线、管风琴底色、民族乐器答句和有节制的打击乐建立戏剧弧线：少年冲撞 → 生命追问 → 战士牺牲 → 怀念母亲与大地 → 四季轮回。

完整保留 **106 小节、四个合唱声部的原始音符、歌词、气声、分声部及表情标记**。沿用原有编制的 28 个 MusicXML 声部组；中音笛 I / II 共用一份分谱。修改钢琴伴奏并完成民族乐器、弦乐、双排键和打击乐编配。词曲署名保留源文件信息。

在 GitHub 文件页点击 **Download raw file**。ZIP 下载后先解压，再用 Sibelius 或 MuseScore 打开 `.musicxml` 文件；不要把 ZIP 直接当作压缩 MusicXML 打开。

总谱设置为 A3 纵向，分谱可在记谱软件中重新排版为 A4。MusicXML 是可编辑乐谱，软件导入后可按本团习惯调整换页、谱表间距和字体。

## 主要处理

| 小节 | 戏剧与配器 |
|---|---|
| 1–19 | 钢琴／颤音琴时钟；低弦托住独唱；二胡与笛子留有呼吸的答句 |
| 20–37 | 6/8 聚合，扬琴承接钢琴快速琶音；弦乐、琵琶、中阮形成不同速度的脉动；保留两处 7/8 |
| 38–44 | 上行低音与 D 音支柱；笙、双排键扩展空间，在追问后聚力 |
| 45–56 | 较丰满的主题回归；二胡、大提琴答句；54 小节后渐退 |
| 57–59 | 管弦断裂与下行；单次低音锣过渡到气声 |
| 60–67 | 保留原作半音张力；弱奏低弦、低音管、笙；自由气声随指挥 |
| 68–77 | 牺牲段：弦乐压力、管风琴、大鼓与定音鼓；短唢呐呼号；75 小节骤收，留呢喃与时钟 |
| 78–91 | 回忆段收去大部分打击乐；二胡与大提琴托住“母亲、大地”；91 小节延长后进入转调 |
| 92–98 | A 小调最后的宽阔高潮；克制的大拍鼓点；96 小节稍慢，98 小节收束 |
| 99–106 | 管风琴和大打击乐退出；随原有延长；“四季”逐渐退远，以 A 小调余音结束 |

## 已完成的检查

32 个 MusicXML 文件全部通过 MusicXML 3.0 XSD 校验。总谱与三份排练合谱通过 music21 解析，均为 106 小节，无导入警告；新写伴奏的 2,438 个声部小节完成时值、音域、延音线和乐器引用检查。四个原合唱声部与源文件逐声部规范化 XML 完全一致。另检查四鼓调音、打击乐换奏休止、古筝共用弦音及延长位置，并用 Verovio 检查总谱和选段谱面。

尚未在 Sibelius／MuseScore 中实际试开或使用真实音源试听。民族乐器的通用 MIDI 回放音色只作近似；现场力度与平衡仍需排练调整。
