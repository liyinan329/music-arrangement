# 配器项目
用于分析与编辑合唱、管弦乐和民族乐器的 MusicXML、MIDI 乐谱。

## 《主题曲》打击乐补全版

已补写五个打击乐声部和定音鼓，保留原曲 88 小节结构及其他 23 个乐谱声部。

- [完整项目 ZIP（总谱、打击乐分谱、改动说明和验证结果）](deliverables/music-arrangement-project.zip)
- [完整总谱 MusicXML](deliverables/music-arrangement-completed.musicxml)
- [打击乐分谱 MusicXML](deliverables/music-arrangement-percussion.musicxml)
- [使用说明与改动摘要](deliverables/使用说明与改动摘要.txt)

点击文件后，使用 GitHub 文件页面的 **Download raw file** 下载；也可以从仓库的 **Code → Download ZIP** 下载整个项目。

MusicXML 可导入 Sibelius、MuseScore 等记谱软件继续编辑。文件已经过 MusicXML 3.0 格式、节拍、延音线、音域和四鼓定音计划检查；尚未使用实际音源试听。
