# 配器项目
用于分析与编辑合唱、管弦乐和民族乐器的 MusicXML、MIDI 乐谱。

## 《时间》修订总谱（当前版本）

保留106小节及原合唱音符、歌词和节奏，提高各器乐声部参与度，将更多钢琴织体移交两组小提琴与二胡，增加军鼓十六分音符、打击乐错位重音及高潮唢呐。二胡使用独立的 `Erhu / Erh.` 标识，总谱只有 `Violin I`、`Violin II` 两组小提琴。

通用演奏提示集中在钢琴谱行，以常用英文标记显示；中文歌词保留并设置 Unicode 字体，移除旧 Opus／SimHei 文字字体及重复提示。此次仅交付总谱，不生成新版分谱。

- **[直接下载修订总谱 MusicXML](https://github.com/liyinan329/music-arrangement/raw/refs/heads/main/deliverables/time-overture/time-overture-revised-full-score.musicxml)**
- [GitHub 总谱文件页](deliverables/time-overture/time-overture-revised-full-score.musicxml)

已通过 MusicXML 3.0 格式、106小节时值、音域、延音线、换奏休止和四鼓调音检查，并完成 music21 导入及 Verovio 谱面检查。当前环境未进行 Sibelius 实机导入或真实音源试听；二胡与唢呐可按独立乐器名称选择本机对应音源。
